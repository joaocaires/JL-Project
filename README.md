# JL-Project

Objetivo

Criar um site romântico e elegante, focado em UX sentimental e visual, utilizando uma estética de "assimetria sofisticada".

Design System & Estilo

Estilo: Romântico, elegante, minimalista com toques de assimetria.

Paleta de Cores:

Primary (Accent): #7F1734

Highlight: #9D0D06

Dark/Border: #710A04

Background: #000000

Estrutura das Páginas

1. Home

Landing: Texto romântico centralizado.

Resumo: Cards de navegação para:

Galeria de Fotos

Retrospectiva Animada

Timeline do Relacionamento

2. Galeria de Fotos

Layout: Grid assimétrico (Masonry style).

Interação:

Cards de tamanhos variados.

Modal: Ao clicar, abre foto em alta resolução + descrição.

Áudio: Gatilho de música específica associada a cada foto/modal.

3. Retrospectiva Animada

Estilo: Spotify Wrapped.

Comportamento: Slides automáticos/manuais, fotos com transições suaves e música de fundo sincronizada.

4. Timeline

Estilo: Visual linear, mantendo a paleta de cores.

Conteúdo: Data + Foto + Descrição de eventos marcantes.
